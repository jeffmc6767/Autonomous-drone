Quick start:
-

Here's how you can start building this yourself:

1. Find the gerbers V3 file. (Production files, Gerbers, gerbersV3), and buy it off a PCB manufacturer
2. Buy all components from the BOM.CSV.
3. Solder on the SMD components onto the PCB
4. Flash the firmware.hex using the USBC port
5. Find the drone frame V3 and print it using PETG or stronger
6. Install all of the hardware
7. Pair with your DJI Goggles and FPV controler
8. FLYYY!!

Features:
- 

- includes 6-axis gyroscope
- up to 99kn/h (theoretical top speed under good conditions)
- 4-5 minutes of flight time
- Easy repairs! 1.2$ per print, 3.5 hours
- up to 4K resolution
- Full ACRO mode
